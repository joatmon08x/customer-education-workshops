LEDGERLY-150 Call results dashboard

Epic Summary:
Billing operators can see how many reminder calls the mock placed and how they ended. The view is limited to the mock book in this workspace.

Objective:
Show call volume and outcomes in one place for the billing operator.

User Stories/Tasks:
[LEDGERLY-151]: As a billing operator, I want a count of calls placed today, so that I can see whether the mock ran. Status: Backlog
[LEDGERLY-152]: As a billing operator, I want outcomes grouped by answered, no answer, and opt-out, so that I can see the mix. Status: Backlog
[LEDGERLY-153]: As a workspace admin, I want the results view limited to the mock book, so that the figures stay inside this workspace. Status: Todo
