LEDGERLY-110 Call scripts and tone

Epic Summary:
Each reminder call uses a short script with a chosen tone. The default tone is calm. A preview plays the script in the mock before a call uses it.

Objective:
Give every reminder call the same short shape, with a tone the workspace admin can choose.

User Stories/Tasks:
[LEDGERLY-111]: As a billing operator, I want a default reminder script, so that every call states the invoice and the amount due. Status: Done
[LEDGERLY-112]: As a workspace admin, I want the script to end with an opt-out line, so that the customer can refuse later calls. Status: In Progress
[LEDGERLY-113]: As a workspace admin, I want to preview a script before it is used on a call, so that I can check the tone in the mock. Status: In Progress
[LEDGERLY-114]: As a billing operator, I want the script to include a pay prompt, so that the customer knows a pay link will follow the call. Status: Todo
[LEDGERLY-115]: As a workspace admin, I want a formal tone and a brief tone in addition to the calm default, so that the call can match the workspace voice. Status: Backlog

Notes/Additional Information:
The script names the invoice and the amount due. It does not state a late fee, and it does not threaten the customer. Preview uses the Grok Voice mock and does not place a call.
