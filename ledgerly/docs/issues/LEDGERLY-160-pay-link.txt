LEDGERLY-160 Pay link after the call

Epic Summary:
After a reminder call, the customer receives a pay link for that invoice. The link points at one invoice and expires after a set number of days.

Objective:
Give the customer a direct way to pay the invoice the call named.

User Stories/Tasks:
[LEDGERLY-161]: As a customer, I want a pay link after the reminder call, so that I can pay the invoice without searching for it. Status: Todo
[LEDGERLY-162]: As a billing operator, I want the pay link tied to <invoice id>, so that the payment lands on the right invoice. Status: Backlog
[LEDGERLY-163]: As a workspace admin, I want the pay link to expire after a set number of days, so that an old link does not stay open. Status: Backlog

Mockups/Designs:
ledgerly/docs/design/call-reminders-review.txt section: Call flow, pay prompt in DR-2

Dependencies:
LEDGERLY-131

Timeframe:
Start Date: 2026-12-08
End Date: 2027-01-30

Stakeholders:
Billing operations. Voice platform. Workspace design. Finance ops.

Notes/Additional Information:
The link is a <pay link> placeholder. This epic does not invent a payment page and does not change the amount due. How many days the link stays valid is still open.
