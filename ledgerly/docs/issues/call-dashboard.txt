Epic Summary:
Billing operators can see how many reminder calls the mock placed and how they ended. The view is limited to the mock book in this workspace.

Objective:
Show call volume and outcomes in one place for the billing operator.

User Stories/Tasks:
As a billing operator, I want a count of calls placed today, so that I can see whether the mock ran.
As a billing operator, I want outcomes grouped by answered, no answer, and opt-out, so that I can see the mix.
As a workspace admin, I want the results view limited to the mock book, so that the figures stay inside this workspace.

Mockups/Designs:
ledgerly/docs/design/call-reminders-review.txt section: Call results dashboard

Dependencies:
Call outcomes and transcripts must finish before this epic starts.
The needed story is the one that saves each call outcome on the invoice.

Timeframe:
Start Date: 2026-12-08
End Date: 2027-01-23

Stakeholders:
Billing operations. Voice platform. Workspace design.

Notes/Additional Information:
This view is not on the dashboard in the running app. Counts come from mocked calls only. The view does not list a phone number.
