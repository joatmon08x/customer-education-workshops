Epic Summary:
The finance lead can see how many reminder calls the mock placed and how they ended. The view is limited to the mock book in this workspace.

Objective:
Show call volume and outcomes in one place for the finance lead.

User Stories/Tasks:
As a finance lead, I want a count of calls placed today, so that I can see whether the mock ran.
As a finance lead, I want outcomes grouped by answered, no answer, and opt-out, so that I can see the mix.
As a finance lead, I want the results view limited to the mock book, so that the figures stay inside this workspace.

Mockups/Designs:
ledgerly/docs/design/call-reminders-review.txt section: Call results dashboard

Dependencies:
Blocked by Call outcomes and transcripts.
The needed story is the one that saves each call outcome on the invoice.

Timeframe:
Start Date: 2027-03-01
End Date: 2027-03-26

Stakeholders:
Billing operations. Voice platform. Workspace design. Finance lead.

Notes/Additional Information:
This view is not on the dashboard in the running app. Counts come from mocked calls only. The view does not list a phone number.
